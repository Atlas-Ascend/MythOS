## Rainbow Council

The Rainbow Council is a multi-perspective advisory projection. It may surface operational, technical, security, evidence, business, human, creative and long-horizon perspectives, but it cannot self-authorize work or declare proof.

Council output must resolve into one of:

- recommendation;
- explicit disagreement;
- missing evidence;
- blocker;
- Packet OS candidate;
- escalation to JANUS / Architect.

## Web weaving

The web is the existing Global Hypernet Fabric. A weave is an evidence-backed edge between two already-known nodes: repository, organ, fabric, runtime, agent, plugin, hardware node, project, calendar event or proof receipt.

No edge is rendered as live merely because it is aesthetically desirable.
